Hi, I’m @100000s

As a freeNation visionary I have been exploring ways to reduce and ultimately eliminate all State monopolies for most of my life.

I’m currently developing TRIM (a Tax Reduction Incentive Mechanism) through which politicians can be automatically rewarded reputationally and compensated for reducing taxes. 

TRIM is a sovereign blockchain that doesn't consume massive amounts of electricity to solve random mathematical puzzles (like Bitcoin's PoW - which inevitably increases mining cost and exclusivity), or require accumulation of tokens as governing stake (like Ethereum's PoS - which inevitably increases governance centralization). TRIM transactions only require smartphones and Raspberry Pis to process and archive blocks, and it does so anonymously. These light nodes compete for transaction fees (which each operator splits 30/70 with his counterpart) and can upgrade the TRIM chain with a strict consensus protocol (TIPs - see repository) which is an improvement on Bitcoin's BIPs and Ethereum's EIPs...

Check out my work, and climb aboard.
